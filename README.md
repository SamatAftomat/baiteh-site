# Байтех — сайт

Одностраничный сайт для **Байтех** — строительной компании в Альметьевске:
песок, щебень, чернозём и глина с доставкой, полусухая стяжка, аренда спецтехники.

- Данные: карточка [2ГИС](https://2gis.ru/almetevsk/firm/70000001103403357) —
  5,0 ★, 7 оценок, 6 отзывов, 31 фото, 11 цен, контакты, рубрики, оплата
- Статический сайт: HTML + CSS + JS, без сборки
- Стиль: «Сигнальный чертёж» (Unbounded + Manrope) — как у сайтов 01–07
